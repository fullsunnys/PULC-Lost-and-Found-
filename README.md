🎓President University Lost Center (PULC)

President University Lost Center (PULC) is a web-based application designed to help the President University community report and find lost or found items. This platform replaces manual reporting with a centralized digital system, making it easier for students, staff, and lecturers to reunite lost belongings with their owners.  

✨ Key Features
  1. Item Reporting: Users can easily report lost or found items by providing descriptions, categories, locations, and supporting images.
  2. Smart Search & Filtering: Browse item listings using keywords and powerful filters like category, location, and date.
  3. Secure In-App Chat: Communicate directly with item reporters or claimants through a private messaging system once a claim is initiated.
  4. Real-Time Notifications: Receive instant web notifications and email alerts for claim updates, new messages, and status changes.
  5. Claim Management: Submit claim requests and verify ownership of found items securely.
  6. Admin Dashboard: Administrators can moderate reports, manage users, and monitor overall system activity.

🛠️ Technology Stack 
  1. Frontend: React.js for the UI, React Router for navigation, and Framer Motion for smooth transitions.
  2. Backend: Express.js (Node.js) for the API and RESTful routing.
  3. Database: PostgreSQL for relational data storage with Prisma ORM for type-safe queries.
  4. Security: JWT-based authentication, bcrypt password hashing, and Role-Based Access Control (RBAC).
  5. Hosting: Vercel for cloud deployment of both frontend and backend.
